# Tela de Login

Tela de login responsiva e acessível, em um único `index.html`.

## Recursos
- Rótulos e mensagens de erro associados aos campos (leitores de tela)
- Validação no envio e ao sair do campo
- Mostrar/ocultar senha e aviso de Caps Lock
- "Lembrar usuário" (salva só o usuário, nunca a senha)
- Estado de carregamento e feedback de sucesso/erro

> Demonstração de front-end: usuário `demo` e senha `123456`. Em produção, a autenticação deve acontecer no servidor.
